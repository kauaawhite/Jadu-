# PikaShort Bot (V16a)

Ultra-premium Telegram URL shortener bot (Smallshorturl integration) with admin dashboard.

Files:
- bot.js
- package.json
- src/database.json

Deploy (Render):
1. Push repo to GitHub.
2. Create new Web Service on Render.
3. Build: npm install
4. Start: npm start
5. Set env: TELEGRAM_BOT_TOKEN=<your token>

Dashboard URL:
https://<your-render-url>/dashboard?token=afiya1310
